# ORYON — downloads

A IA de programação que nasce no seu PC: pensa à vista, escreve código avançado, roda os testes e corrige antes de entregar. Treinada do zero e rodando inteira na sua máquina.

**Página:** https://oryon-ia.github.io

- Baixe o `ORYON.exe` mais recente em [Releases](https://github.com/oryon-ia/oryon/releases/latest).
- Windows 10 ou 11 (64 bits). Sem conta, sem assinatura.
- Na primeira vez o Windows mostra "O Windows protegeu o computador", porque o app ainda não tem assinatura digital: clique em **Mais informações → Executar assim mesmo**.
- O app se atualiza sozinho: quando sai versão nova, aparece a faixa "Atualizar" no topo.

Versão prévia: o modelo de fala treinado do zero chega numa atualização.
